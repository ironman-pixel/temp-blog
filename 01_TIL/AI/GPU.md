## GPU: 
VGU카드 그래픽카드 등으로 불림
CPU와 메모리 등이 연산한 내용을 이미지, 영상화하여 모니터 등으로 출력해주는 장치

- 내장그래픽
	- 이미 메인보드에 GPU가 내장된것
- 외장그래픽
	- 메인보드에 GPU 기판을 장착하여 사용하는 경우

_보통 외장그래픽이 더 좋은 성능을 냄_

## 외장 그래픽카드 종류
NVIDIA, AMD 두 회사가 가장 큼

### NVIDIA
- 전문가/서버용의 쿼드로 QUADRO 제품
- 일반사용자용의 지포스 GEFORCE 제품

지포스 중에서도 저가/주력/고가 제품 등으로 제품군을 세부적으로 나눔

### AMD 
- 전문가/서버용의 파이어프로 FIREPRO 제품
- 일반사용자용의 라데온 RADE ON  제품

내장그래픽 기능이 기본적으로 매우 높음. 그래서 저가 제품은 많이 판매하지 않고, 주력/고가 제품 위주로 제품군을 출시함


## 그래픽카드 구분하는 방법

일반사용자용 그래픽은 세 부류

- 보급형
- 중/고급형
- 하이엔드/최고급형

_그래픽카드의 메인칩셋(GPU) 의 모델명이 성능과 가격에 가장 큰 비중을 차지하기 때문에 GPU 이름이 곧 그래픽카드의 이름인것으로 불리고 있다_

### NVIDIA 지포스
- 보급형: 05, 10, 20, 30, 40 의 GT시리즈
- 중/고급형: 50, 60 의 GTX시리즈
- 하이엔드: 70, 80, 90 제품

최근엔 내장그래픽의 성능이 좋아지며 보급형 단종
2000 시리즈부터 GTX 에서 RTX 로 이름 변경

### AMD 라데온
고급형, 하이엔드 제품만 출시 (모두 RX 시리즈만 있음)
RX 시리즈 이전에 R, HD 시리즈 있었으나 이제는 보기 드물며 사용하지 않음


## 선택하는 방법

**앞자리로 출시된 시기, 뒷자리로 성능 확인**
**구형 시리즈로 내려갈때 성능을 나타내는 숫자가 1정도 내려간다고 보면됨**

### 예시 GTX1060 OC PCI-E 3GB GDDR5 192BIT WDP/HDMI/DVI-D

- GTX1060
  엔비디아 제조사의 지포스 계열, 1000 시리즈 중 고급형.
- OC
  오버클럭킹의 줄임말.
  제조사가 똑같은 GTX1060 칩이더라도 오버클럭을 한 후 조금 더 성능을 좋게 만들어서 많이 판매하기 위해 자주 사용함.
  약간의 차이이지 모델명을 뛰어넘을 정도로 차이 나지 않음 1-2%차이.
- PCI-E
  PCI-E 포트에 장착하는 방식의 그래픽카드를 말함.
  대부분의 그래픽카드가 PCI-E 슬롯을 사용함.
- 3GB 
  그래픽카드에 3GB의 그래픽 메모리가 장착되어있음.
  모델명에 따라 주로 장착되는 메모리가 정해져 있음.
- GDDR5
  위의 3GB 메모리가 그래픽전용 GDDR5 메모리 모듈로 장착됨.
- 192BIT
  그래픽 메모리와 GPU 연산에 사용되는 BIT (보통, 높으면 좋음).
- DP
  그래픽카드 출력단자로 DP가 있음.
- HDMI
  그래픽카드 출력단자로 HDMI가 있음.
- DVI-D
  그래픽카드 출력단자로 DVI-D가 있음.


위 설명과 같이 OC, 메모리 용량은 유명 브랜드 제품들이라면 크게 중요하지 않음.

> **중요사항**
> 모델명 뒤에 Ti, SU(슈퍼), XT, SE 등의 추가 문구가 붙는 제품들이 보임.
> 
> 지포스는 SE < 노멀 < 슈퍼 < Ti
> 성능이 노멀 대비 더 뛰어난 제품엔 Ti 나 SUPER를 붙이며, 성능이 조금 떨어지는 경우 SE를 붙임
> 
> 라데온은 노멀 < XT < XTX
> 라데온의 경우 성능이 노멀 대비 더 뛰어난 제품엔 XT 혹은 XTX를 붙임
> 
> 
> OC 랑은 조금 다른 개념임
> 일반 < 일반OC < Ti < Ti OC 대략 성능은 이런식으로 볼 수 있으며 
> OC 라는것은 NVIDIA 가 아닌 기가바이트나 갤럭시, 아수스, 이엠텍 등 그래픽카드 제조사가 NVIDIA 에서 구매한 그래픽칩에 추가적인 OC 를 하는것이기 때문

### 사이즈
- 그래픽카드 두가지 너비: 일반형 / 슬림 (LP)형

그래픽 기판 자체가 넓거나 좁은 제품이 있지만, 더 중요한건 브라켓임.

그래픽카드 자체가 슬림하더라고 일반 브래켓(출력 단자가 있는 부분의 철로된 가이드)을 사용한다면 일반적인 미들타워 PC 에 사용 가능함.
하지만 슬림PC 라면 슬림브라켓(LP브라켓)이면서 제품도 슬림해야만 사용 가능.

### 팬(쿨러)
쿨러는 보통 무팬(방열판 모델), 1팬, 2팬, 3팬 제품이 있음.
같은 모델일때 팬의 수가 많아질수록 시끄러울수도 있으나, 기판 수명에 대한 기대치는 더 길어짐
_대부분의 그래픽카드 불량이 장시간 과열에 노출되어 생김_

저사양일수록 팬이 적어지며, 고사양일수록 팬이 많아짐

일반적으로 
저급형제품: 무팬, 1팬
중/고급형 제품: 1팬, 2팬
최고급형 제품: 1팬, 2팬, 3팬

### 보조전원 유무
최근 출시된 대부분의 파워 서플라이는 
그래픽카드 전용 6핀 혹은 8핀 보조전원이 달려있지만, 
일부 PC/오래된 PC의 경우 없는 경우도 있기 때문에 
제품에 6핀 보조전원 연결이 필요한지 확인 후, 
필요한 경우 6핀 보조전원 케이블을 같이 구매해야 함. (신품의 경우 보통 제품 구성에 포함되어있음)

### 브랜드
사람마다 보는 시각이 다름
뭐가 낫다기 보다는 
기본적으로 같은 모델(칩)을 가진 제품은 브랜드가 달라도 비슷비슷하다 정도로 확인 가능
AS를 얼마나 잘해주나 확인하면 됨

### 그래픽카드 브랜드와 호환성
본인의 PC 에 그래픽카드를 설치할 경우, **메인보드와의 호환성**, **파워 용량**을 반드시 고려해야 함.
최신 고성능 그래픽카드는 전력소비가 높기 때문에 파워서플라이를 교체하는 경우가 있음.

### 추천 모델
- NVIDIA GeForce RTX 4090 또는 NVIDIA GeForce RTX 4070: 
  최상위 게이밍 그래픽카드, 최고급 게임 설정에서도 뛰어난 퍼포먼스를 제공.
  24GB의 VRAM과 높은 클럭 속도 제공, 고해상도 게임과 3D 작업에 적합
- NVIDIA GeForce GTX 1660 Super: 
  가격대비 성능이 뛰어난 중저가형 모델.
  Full HD 게이밍과 기본적인 그래픽 작업을 위한 용도로 충분한 성능.

- AMD Radeon RX 7900 XTX:
  NVIDIA의 고급형 제품과 견줄만한 성능을 갖춘 AMD 플래그십 모델.
  4K 해상도에서 강력한 성능.
- AMD Radeon RX 7800 XT:
  가성비가 뛰어난 고사양 그래픽카드.
  높은 VRAM 용량 덕분에 게이밍 및 영상 편집에도 적합.
- AMD Radeon RX 6600:
  중저가형 그래픽카드.
  Full HD 해상도에서 충분한 성능.
  가벼운 게임플레이, 영상시청, 인터넷 사용 적합.

용어 정리
- DLSS 3.0: 프레임 두개 사이를 채워넣는것
- ray-tracing: 광선 전달을 모델링 하는것
- TDP: 
  열 설계 전력(Thremal Design Power) 의 약자.
  CPU나 그래픽카드와 같은 컴퓨터 부품이 최대 부하 상태에서 발열하는 열의 양을 와트(W) 로 나타낸것.
  즉, 높을수록 강력한 쿨링 시스템이 필요.
- PCle 슬롯:
  최신 그래픽키드 및 NVMe SSD 연결을 위한 필수 슬록
