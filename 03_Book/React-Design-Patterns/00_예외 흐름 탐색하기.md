## 1. 다른 컴포넌트에서 발생한 오류
### 오류(서드파티 or API or 마이크로 서비스)
조건문을 추가하거나 error boundary 추가 (UI코드 복잡성 증가)

error boundary: 
자식 컴포넌트의 JS 오류를 잡아서 로그를 기록하고 애플리케이션 전체가 crash 하지 않도록 fallback UI를 표시.
렌더링 과정, 생명주기 메서드, 하위 트리 컴포넌트 생성자에서 발생하는 에러 포착
